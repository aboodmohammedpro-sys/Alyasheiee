# 36. استراتيجية CI/CD (GitHub Actions)

## التكامل المستمر (CI)
كل عملية دفع (Push) لبرنش `develop` أو `feature/*` ستطلق الاختبارات التالية:
1. **Linting**: التنسيق البرمجي PSR-12.
2. **التحليل الساكن**: PHPStan (المستوى 5+).
3. **الاختبارات**: تشغيل `php artisan test` باستخدام PostgreSQL.
4. **تدقيق الأمان**: تشغيل `composer audit`.

## النشر المستمر (CD)
النشر الآلي لبيئة الاختبار أو الإنتاج عند الدمج في `main`:
1. **البناء**: تثبيت الاعتمادات وتجميع الأصول.
2. **التهجير**: تشغيل `php artisan migrate --force`.
3. **التحسين**: كاش الإعدادات والمسارات.

## إدارة الأسرار
يجب تخزين المفاتيح الحساسة في GitHub Secrets:
- `DB_PASSWORD`
- `APP_KEY`
- `SSH_PRIVATE_KEY` (للنشر)
