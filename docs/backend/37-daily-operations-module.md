# 37. موديول العمليات اليومية (Daily Operations Module)

## نظرة عامة
هذا الموديول هو المحرك الميداني للنظام، حيث تتدفق البيانات التشغيلية يومياً من المواقع ليتم معالجتها واعتمادها.

## الكيانات الأساسية (Entities)
1. **السجل اليومي (DailyLog)**: الحاوية الأساسية لكل بيانات اليوم في مشروع محدد.
2. **الحضور العمالي (LaborAttendance)**: تسجيل من حضر ومن غاب.
3. **ساعات العمل (Labor/Equipment Hours)**: تتبع الوقت الفعلي للعمل.
4. **النقلات (MaterialTrips)**: تتبع نقل المواد (رمال، أسمنت، إلخ).
5. **الإنجاز اليومي (DailyProgress)**: تحديث نسب الإنجاز للمهام.
6. **المرفقات (Attachments)**: الصور والتقارير الورقية الممسوحة ضوئياً.

## قواعد العمل (Business Rules)
- **التبعية**: يرتبط السجل اليومي بمشروع واحد وتاريخ واحد فقط.
- **تدرج السلطة**: يقوم المراقب (Recorder) بالإدخال، والمراقب الأول (Senior Recorder) بالمراجعة والاعتماد.
- **قاعدة التجميد (Freezing)**: بمجرد اعتماد السجل، يُمنع التعديل عليه نهائياً من قبل المراقبين.
- **نطاق الرؤية**: لا يرى المراقب إلا المشاريع المعينة له رسمياً في جدول التعيينات.

## طبقة الخدمات (Services)
- `DailyLogService`: إدارة دورة حياة السجل (إنشاء، إرسال للمراجعة، اعتماد).
- `AttendanceService`: معالجة حضور العمال.
- `OperationReportService`: استخراج التقارير اليومية المجمعة.

## مسارات الـ API (Endpoints)
- `POST /daily-logs`: إنشاء مسودة يومية.
- `PUT /daily-logs/{id}/submit`: إرسال للاعتماد.
- `PATCH /daily-logs/{id}/approve`: (Senior Recorder فقط) اعتماد السجل.
- `GET /daily-logs?project_id=X`: استرجاع السجلات بناءً على الصلاحية.
